# Steuerung:

Spielerbewegung: W-A-S-D
Projektilschuss: linke Maustaste
Springen: Spacebar (Doppelsprung möglich)
CHEAT Level abschließen ohne alle Gegner zu töten: n-Taste

# Gameplay:

Lassen Sie sich nicht von den Antikörpern berühren, diese verursachen dem Spieler Schaden. Schießen Sie auf die grauen Schäfchenzellen, um sie zu infizieren. Dadurch platzen die Schäfchen und Miniviren werden auf die Antikörper geschleudert, welche ihre Schilde zerstören. Schießen Sie die Antikörper ohne Schilde ab, denn die Miniviren haben auf diese keinen Einfluss. Sie können den Schild der Antikörper auch selbst mit Schüssen zerstören, dies dauert allerdings erheblich länger!
Zerstören Sie alle Antikörper, um das Level zu beenden.

# Rouge-like Mechanik umgesetzt:

Bei erfolgreichem Beenden eines Levels kann das nächste Level gestartet werden, welches vom Raumumfang größer ist und mehr Gegner / Schäfchenzellen beinhaltet als das Level zuvor.
